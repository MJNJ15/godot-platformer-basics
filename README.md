# Godot Platformer Basics

A simple 2D platformer project built to learn the fundamentals of game development with **Godot 4**.
No specific theme or story — the main focus is understanding core mechanics and workflow.

## 🎯 Learning Objectives

- Understand Godot project structure
- Create a character with basic movement and jumping
- Build a simple level using tilemaps
- Add hazardous objects (spikes, pits)
- Create basic UI (Main Menu → Game → Game Over)
- Connect scenes together

## 🛠️ Tools

- Godot 4.7.1
- Aset: Abstract Platformer by Kenney Vleugels (Kenney.nl)
